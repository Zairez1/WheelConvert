# WheelConvert

Конвертер файлов для Windows в виде колеса. Выделил файл, нажал Alt, выбрал формат, и готовый файл появился рядом с исходным.

**[⬇ Скачать установщик](https://github.com/Zairez1/WheelConvert/releases/latest/download/WheelConvert-Setup.exe)**

## Как пользоваться

- Выделите файл в Проводнике и коротко нажмите **Alt**
- Или нажмите на файл правой кнопкой → «Конвертировать в другой формат…» (в Windows 11: «Показать дополнительные параметры»)
- Или откройте WheelConvert и перетащите файл на колесо

## Форматы

Фото, видео, аудио, архивы, текст и данные (csv, tsv, json) работают сразу, ffmpeg уже в установщике.
Документам, таблицам, презентациям и PDF нужен бесплатный [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/).

Программа обновляется сама: раз в сутки проверяет этот репозиторий и ставит новую версию, когда колесо закрыто. Отключить можно в меню значка в трее.
